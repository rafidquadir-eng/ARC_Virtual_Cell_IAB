Usage: vcc [OPTIONS] COMMAND [ARGS]...

  vcc — submit predictions to the Virtual Cell Challenge.

  Run `vcc version` for version details, or `vcc COMMAND --help` for a
  command.

Options:
  --json           Emit machine-readable JSON instead of human-readable text.
  --profile TEXT   Named credential profile [env: VCC_PROFILE].
  --endpoint TEXT  Base URL of the VCC site to talk to [env: VCC_ENDPOINT].
  --version        Show the vcc version and exit.
  -h, --help       Show this message and exit.

  cancel    Abandon an in-progress submission, freeing your team's slot.
